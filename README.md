# دفتریار

برنامه حسابداری برای دفتر خدمات نقشه‌برداری و امور ثبتی — با فلاتر.

## امکانات نسخه ۲ — حسابداری دوطرفه
هسته برنامه یک سیستم حسابداری دوطرفه (Double-Entry) استاندارد است:
- **چارت حساب‌ها**: تعریف/ویرایش/حذف حساب با نوع (دارایی، بدهی، حقوق صاحبان سرمایه، درآمد، هزینه) و امکان حساب والد/زیرحساب — از بخش تنظیمات
- **اسناد حسابداری**: ثبت سند دستی چندسطری با اعتبارسنجی توازن بدهکار=بستانکار، به‌علاوه دو فرم سریع «ثبت دریافت» و «ثبت هزینه/پرداخت» که در پس‌زمینه سند دوطرفه صحیح می‌سازند
- **دفتر حساب (دفتر معین/کل)**: مشاهده گردش و مانده هر حساب
- **تراز آزمایشی**: جمع بدهکار/بستانکار و مانده تمام حساب‌ها
- **گزارش سود و زیان**: در بازه دلخواه، با نمودار توزیع هزینه‌ها به تفکیک حساب

روی این هسته، **پروژه و کارفرما به‌عنوان قابلیت گزارش‌گیری** اضافه شده‌اند:
- تعریف کارفرما (نام، تماس، کد ملی، آدرس) — از تنظیمات یا هنگام تعریف پروژه
- تعریف پروژه و تخصیص کارفرما به آن؛ هر سطر سند می‌تواند به یک پروژه برچسب بخورد تا دریافتی/هزینه هر پروژه جداگانه قابل پیگیری باشد

سایر امکانات:
- داشبورد خلاصه وضعیت مالی (مانده دارایی، درآمد، هزینه، سود/زیان خالص)
- ذخیره کاملاً محلی (SQLite) + پشتیبان‌گیری/بازیابی با فایل JSON (شامل چارت حساب‌ها و همه اسناد)

## ساخت APK
پروژه فاقد پوشه‌های android/ios است و به‌صورت خودکار توسط GitHub Actions ساخته می‌شود.

1. یک ریپازیتوری در گیت‌هاب بسازید (مثلاً `daftaryar`) و این پوشه را push کنید:
   ```bash
   git init
   git add .
   git commit -m "نسخه اول دفتریار"
   git branch -M main
   git remote add origin https://github.com/<username>/daftaryar.git
   git push -u origin main
   ```
2. به تب **Actions** در گیت‌هاب بروید؛ ورک‌فلو «Build APK» به‌طور خودکار اجرا می‌شود
   (چند دقیقه طول می‌کشد چون `flutter create` اسکلت اندروید را در همان اجرا می‌سازد).
3. پس از پایان، از بخش artifacts همان اجرا فایل `daftaryar-apk` را دانلود کنید — شامل چند APK
   به تفکیک معماری (arm64-v8a برای اکثر گوشی‌های امروزی).

## توسعه محلی (اختیاری، در ترموکس یا هر محیط دیگر)
اگر خواستید مستقیماً روی گوشی/کامپیوتر خودتان اجرا و تست کنید:
```bash
flutter create --platforms=android,windows --org com.parshan .
flutter pub get
flutter run
```
(این دستور فقط پوشه‌های پلتفرم را اضافه می‌کند و به pubspec.yaml یا lib/ دست نمی‌زند.)

## ساختار داده
- `clients` — کارفرمایان
- `projects` — پروژه‌ها (هر پروژه به یک کارفرما وصل است)
- `accounts` — چارت حساب‌ها (سلسله‌مراتبی، با نوع و حساب والد)
- `journal_entries` — سرصفحه اسناد حسابداری (تاریخ، شرح)
- `journal_lines` — سطرهای هر سند (حساب، بدهکار/بستانکار، برچسب پروژه اختیاری)

سود/زیان خالص = (مانده حساب‌های درآمد) − (مانده حساب‌های هزینه)، بر اساس مانده طبیعی هر نوع حساب.

توجه: نسخه ۲ ساختار دیتابیس را نسبت به نسخه ۱ کاملاً تغییر داده (فایل دیتابیس جدید `daftaryar_v2.db`)؛ در صورت نصب نسخه قبلی روی گوشی، داده‌های قدیمی به‌طور خودکار منتقل نمی‌شوند.

## نکات بعدی برای توسعه
- افزودن گزارش خروجی PDF/Excel از دفتر حساب و تراز آزمایشی
- افزودن یادآور اقساط معوق کارفرمایان
- تفصیلی کردن حساب دریافتنی به تفکیک هر کارفرما (در صورت نیاز به ردیابی دقیق‌تر مطالبات)
